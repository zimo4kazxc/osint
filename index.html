OSINT & Doxing

Полный практический курс: от открытых источников до готового досье. Методология, тулинг, OPSEC, пайплайн.

01 · Введение в OSINT

Основы

Что такое разведка по открытым источникам, чем она отличается от доксинга, и как устроен цикл сбора.

Определение

OSINT (Open Source Intelligence) — разведка по открытым источникам. Это сбор и анализ информации из публично доступных источников: веб-страниц, соцсетей, реестров, баз данных, медиа, метаданных. Источник считается открытым, если доступ к нему не требует взлома, обхода авторизации или нарушения закона.

Доксинг — это финальная стадия: агрегация собранных данных в персональное досье и его публикация. Технически доксинг = OSINT + агрегация + деанонимизация. Разница между ними — в цели: OSINT отвечает на вопрос «что можно узнать», доксинг — «кто это и где живёт».

Ключевой принцип
OSINT работает только с открытыми источниками. Всё, что требует пароля, взлома или подкупа — вне метода. Это не мораль, это определение.

Цикл разведки

  1. Постановка задачи — что именно мы ищем: имя, ник, домен, аккаунт, местоположение.
  2. Планирование — какие источники релевантны, какие инструменты, какой бюджет времени.
  3. Сбор — первичный «широкий заброс»: поисковики, соцсети, реестры.
  4. Обработка — нормализация: единый формат, дедупликация, извлечение сущностей.
  5. Анализ — связывание сущностей, проверка гипотез, поиск противоречий.
  6. Отчёт — досье, таймлайн, граф связей, выводы с уровнем уверенности.

Типы источников

ТипПримерыЦенность
ПоисковикиGoogle, Bing, Yandex, DuckDuckGoВысокая — точка входа
СоцсетиVK, Telegram, Instagram, XОчень высокая — личные данные
РеестрыЕГРЮЛ, WHOIS, судебные базыВысокая — официальные данные
УтечкиHaveIBeenPwned, DeHashedСредняя — устаревшие данные
МедиаФото, видео, EXIFВысокая — геолокация, время
АрхивыWayback Machine, archive.todayСредняя — удалённое

Юридическая рамка

В большинстве юрисдикций сбор открытой информации сам по себе не преступен. Преступным становится: обход авторизации, доступ к закрытым данным, преследование (stalking), шантаж, публикация данных с целью причинения вреда. Разделяй сбор и применение.

02 · OPSEC исследователя

Основы

Как не оставить следов и не сжечь себя в процессе сбора.

Почему OPSEC критичен

Каждый твой запрос — это след. Поисковики логируют IP, соцсети связывают аккаунты, сайты читают User-Agent. Если исследуешь кого-то, а он заметит интерес — сбор провален. OPSEC — это гигиена.

Уровни изоляции

Базовый
  • Отдельный браузер для OSINT (не основной).
  • VPN с оплатой криптой, не логирующий.
  • Отключённые cookies, JavaScript через NoScript где возможно.
  • Отдельный профиль почты без привязки к телефону.
Продвинутый
  • Изолированная VM (Whonix, Tails) для чувствительных сессий.
  • Tor для источников, где важна анонимность.
  • Отдельные «персоны-приманки» для соцсетей.
  • Разные IP для разных этапов.
Правило одной персоны
Каждая задача — отдельная персона. Не смешивай почту, ник, стиль письма между задачами. Перекрёстная корреляция — самый частый способ сжечь себя.

Артефакты, которые ты оставляешь

  • IP — виден любому серверу.
  • User-Agent — версия ОС и браузера.
  • Cookies — связывают сессии.
  • Referer — откуда пришёл.
  • Время — часовой пояс по активности.
  • Стиль — лексика, опечатки, эмодзи.
  • Метаданные файлов — если отправляешь документы.

Гигиена аккаунтов

Разделяй аккаунты по задачам. Никогда не используй личный email для регистраций в OSINT-сервисах. Не переиспользуй пароли. Для каждого сервиса — своя почта-однодневка (SimpleLogin, AnonAddy).

03 · Инфраструктура

Основы

Что нужно подготовить до начала работы: рабочие станции, почты, браузеры, хранилища.

Рабочая станция

КомпонентЗачем
VM с Kali/ParrotТулинг из коробки
Whonix / TailsАнонимность
Отдельный браузерИзоляция профиля
Зашифрованный дискХранение данных

Почты и идентичности

  • ProtonMail / Tutanota — анонимные ящики.
  • SimpleLogin / AnonAddy — алиасы.
  • Виртуальные номера — для верификаций (не для злоупотреблений).

Хранилище и организация

OSINT — это про объёмы. Нужна структура:

case/
├── 01_raw/          # сырые данные
├── 02_normalized/   # приведённые к единому виду
├── 03_analysis/     # аналитика
├── 04_report/       # финальное досье
├── media/           # фото, видео
├── logs/            # журнал действий
└── sources.md       # таблица источников
Журнал действий
Веди лог: что, когда, где искал, что нашёл. Без него через сутки ты не вспомнишь, откуда взялась та или иная зацепка.

Тулинг первой необходимости

  • Sherlock / Maigret — поиск юзернеймов.
  • theHarvester / Amass — сбор по домену.
  • Maltego — графы связей.
  • ExifTool — метаданные.
  • Recon-ng — фреймворк.
  • SpiderFoot — автоматизация.

04 · Footprinting

Сбор данных

Первичный широкий сбор: что известно о цели из открытых источников.

Что такое footprinting

Footprinting — это «отпечаток» цели в открытых источниках. Задача — собрать максимально широкий срез до углубления в детали.

Поисковые операторы

ОператорДействие
site:Поиск по конкретному сайту
filetype:Тип файла (pdf, xlsx, doc)
intitle:Слово в заголовке
inurl:Слово в URL
intext:Слово в тексте
"…"Точная фраза
OR / |Альтернатива
-Исключение
..Диапазон чисел
cache:Кэш страницы

Примеры запросов

site:example.com filetype:pdf
intitle:"index of" "backup"
inurl:admin login
"Иван Петров" site:vk.com
filetype:xlsx "контакты" "телефон"

Google Dorks

Комбинации операторов, нацеленные на утечки и открытые директории. Классика жанра:

  • Открытые листинги директорий: intitle:"index of".
  • Конфиги: filetype:env, filetype:conf.
  • Таблицы: filetype:xlsx intext:@gmail.com.
  • Бэкапы: filetype:sql, filetype:bak.

Другие поисковики

  • Bing — иногда находит то, что Google пропустил.
  • Yandex — силён по русскоязычному сегменту.
  • DuckDuckGo — без персонализации.
  • Shodan / Censys — поиск по устройствам и сервисам.
  • FOFA / ZoomEye — аналоги Shodan.
  • Wayback Machine — история страниц.
Сначала ширина, потом глубина
Не углубляйся в первый же найденный след. Сначала собери все зацепки, потом ранжируй их по значимости.

05 · SOCMINT

Сбор данных

Разведка по социальным сетям — самый богатый источник персональных данных.

Почему соцсети — золото

Люди сами публикуют: имя, фото, геолокацию, круг общения, работу, интересы, распорядок дня. Соцсети — это добровольный дамп персональных данных.

Что искать в профиле

  • Имя и псевдонимы — включая девичью фамилию.
  • Дата рождения — часто в постах-поздравлениях.
  • География — геотеги, чекины, фон фото.
  • Работа — компании, должности, коллеги.
  • Образование — школы, вузы, выпуски.
  • Семья — родственники в друзьях.
  • Привычки — спортзал, кафе, маршруты.
  • Техника — по фото и постам.
  • Питомцы — клички часто = пароли.

Платформы и специфика

ПлатформаЧто даёт
VKПолные профили, музыка, группы, друзья
TelegramКаналы, чаты, юзернеймы, номер
InstagramВизуал, сторис, геотеги, связи
X (Twitter)Мнения, связи, ретвиты, время
FacebookСемья, события, работа
LinkedInКарьера, коллеги, навыки
TikTokМолодая аудитория, локации
GitHubEmail в коммитах, проекты, стек

Методика анализа профиля

  1. Сохрани профиль (архив, скриншоты).
  2. Выпиши все видимые поля: имя, ник, bio, ссылки.
  3. Пройди по фото: фон, геотеги, отражения, тени.
  4. Изучи друзей: общие связи = подтверждение личности.
  5. Пройди по лайкам и комментариям: интересы, связи.
  6. Найди ранние посты: часто там больше личного.
  7. Проверь архивы: удалённое часто сохранилось.
Не пались
Не заходи в профиль со своего основного аккаунта — увидишься в «просмотрах». Используй отдельную персону или публичный просмотр.

Инструменты SOCMINT

  • Social Searcher — поиск по соцсетям.
  • Instaloader — выгрузка Instagram.
  • TGStat — статистика Telegram-каналов.
  • Twint-архивы — старые твиты.
  • SNScrape — скрейпинг соцсетей.

06 · Юзернейм-энумерация

Сбор данных

Один ник — сотни платформ. Как найти все аккаунты человека по псевдониму.

Логика метода

Люди переиспользуют ники. Если цель использует shadow_wolf на одной платформе — с высокой вероятностью тот же ник есть и на других. Задача — проверить все платформы разом.

Инструменты

ИнструментТип
SherlockCLI, Python
MaigretCLI, Python, подробный отчёт
WhatsMyNameВеб-база
NamechkВеб
KnowEmВеб, коммерческий
SnoopCLI

Sherlock — пример запуска

git clone https://github.com/sherlock-project/sherlock
cd sherlock
pip install -r requirements.txt
python3 sherlock shadow_wolf --timeout 2
# вывод: список платформ с найденными профилями

Maigret — расширенный вариант

pip install maigret
maigret shadow_wolf --html
# генерирует HTML-отчёт со всеми найденными аккаунтами,
# включая извлечённые данные: bio, аватар, доп. ссылки

Что делать с результатом

  • Отфильтруй ложные срабатывания (проверь каждый профиль вручную).
  • Свяжи аккаунты по аватару, bio, дате регистрации.
  • Проверь пересечения: одни и те же подписчики = один человек.
  • Извлеки новые сущности: email в bio, ссылки на другие соцсети.
Мульти-ник
Цель может использовать несколько ников. Собери все варианты и прогоняй каждый. Пересечение результатов по платформам = подтверждение.

Вариации и деформации

Пробуй:

  • Замены: _, ., -.
  • Числа: год рождения, 007, 1337.
  • Регистр: ShadowWolf, shadowwolf, SHADOW_WOLF.
  • Латиница/кириллица: визуальные двойники.
  • Усечения: shadow, wolf, sw.

07 · Email и телефон

Сбор данных

Как из email или номера вытащить максимум: аккаунты, утечки, соцсети.

Email как ключ

Email — это якорь цифровой личности. С него регистрируются аккаунты, на него приходят чеки, он светится в утечках.

Что можно узнать из email

  • Зарегистрированные аккаунты (через сброс пароля).
  • Участие в утечках (HaveIBeenPwned).
  • Профиль Gravatar (аватар, доп. данные).
  • Связанные сервисы (через сервисы проверки).
  • Имя владельца (из формата ivan.petrov@…).
  • Домен компании (если корпоративный).

Инструменты

ИнструментФункция
HaveIBeenPwnedПроверка утечек
DeHashedПоиск по утечкам (платно)
Hunter.ioКорпоративные email
HoleheПроверка регистраций по email
EmailRepРепутация email
GravatarПрофиль по email-хешу

Holehe — пример

pip install holehe
holehe target@example.com
# проверяет ~120 сервисов, показывает где email зарегистрирован

Телефон как ключ

Номер — ещё более сильный якорь: он привязан к аккаунтам, банкам, мессенджерам. В РФ номер часто = паспорт.

Что можно узнать из номера

  • Оператор и регион (по префиксу).
  • Аккаунты Telegram/WhatsApp (через добавление в контакты).
  • Аватар и имя в мессенджерах.
  • Привязка к соцсетям (поиск по номеру в VK/OK).
  • Утечки (номер часто в базах).

Инструменты

  • NumLookup / Truecaller — определение.
  • GetContact — как записан в чужих контактах.
  • PhoneInfoga — OSINT по номеру.
  • Telegram — добавь номер в контакты, посмотри профиль.
  • WhatsApp/Instagram — проверка регистрации.
Не жги номер
Проверка номера в мессенджерах оставляет след. Делай это с отдельного аккаунта/номера.

Связка email + телефон

Часто email и телефон взаимно подтверждают друг друга. Найди один — проверь второй. Совпадение = высокая уверенность.

08 · Домены и IP

Сбор данных

Инфраструктурная разведка: кто стоит за доменом, какие сервисы, какие утечки.

WHOIS

WHOIS даёт регистратора, даты регистрации/обновления, иногда контакты (часто скрыты приватностью).

whois example.com
# Registrar, Creation Date, Name Servers, Registrant (если открыт)

DNS

DNS-записи раскрывают инфраструктуру: почта, поддомены, сервисы.

dig example.com ANY
dig +short mx example.com
dig +short txt example.com
host -t ns example.com

Поддомены

Поддомены — часто забытые, незащищённые сервисы (dev, staging, admin).

  • Amass — пассивный и активный enum.
  • Subfinder — быстрый пассивный enum.
  • crt.sh — Certificate Transparency логи.
  • dnsdumpster — веб-визуализация.
amass enum -passive -d example.com
subfinder -d example.com -o subs.txt
curl -s "https://crt.sh/?q=%25.example.com&output=json" | jq -r '.[].name_value'

IP и Shodan

По IP можно узнать открытые порты, сервисы, версии, иногда — устройство.

nmap -sV -p- target_ip
shodan search hostname:example.com
censys search example.com

Certificate Transparency

Каждый выданный SSL-сертификат логируется. CT-логи — золотая жила для поиска поддоменов и связанных доменов.

  • crt.sh
  • CertStream
  • Facebook CT Monitor

Архивы и история

  • Wayback Machine — старая версия сайта.
  • archive.today — снимки страниц.
  • urlscan.io — сканы и скриншоты.
Пассивно vs активно
Пассивный сбор (CT-логи, архивы) не касается целевого сервера. Активный (nmap, сканеры) — касается. Второе заметно, делай только в рамках легального скоупа.

Утечки инфраструктуры

  • Открытые S3-бакеты.
  • Открытые Git-репозитории с .env.
  • Открытые Kibana/Elasticsearch.
  • Открытые Jenkins/CI.
  • Открытые базы (MongoDB, Redis).

09 · Геолокация

Сбор данных

Как по фото, видео и тексту определить место. Основной навык доксинга.

GeoOSINT — что это

Геолокация по открытым данным: определение координат по изображению, видео, постам, метаданным. Основной метод — визуальные ориентиры + сопоставление с картами.

Методика по фото

  1. Найди уникальные ориентиры: вывески, здания, памятники.
  2. Определи язык вывесок — регион.
  3. Определи сторону света по теням и солнцу.
  4. Сопоставь с Google Maps / Yandex Maps / Bing.
  5. Используй Street View для подтверждения.
  6. Проверь по спутниковым снимкам.

Инструменты

ИнструментНазначение
Google Maps / EarthБазовый поиск
Yandex MapsРФ, СНГ
Bing MapsАльтернатива
OpenStreetMapОткрытые данные
SunCalcПозиция солнца по времени
PeakVisorГоры и хребты
Overpass TurboЗапросы по OSM
MapillaryКраудсорсные панорамы

Работа с тенями

Тень даёт три вещи: время суток, направление на север, высоту солнца. По этим данным можно определить широту и время. SunCalc — онлайн-инструмент, покажет положение солнца для любой точки и времени.

По видеозаписи

  • Покадровый разбор: вывески, номера, одежда.
  • Фон: архитектура, растительность, рельеф.
  • Звук: язык, акцент, шумы (поезда, трамваи).
  • Движение: направление, скорость, время.

Геолокация по соцсетям

  • Геотеги в постах и сторис.
  • Фон фото (кафе, спортзал, офис).
  • Чекины в VK/Facebook.
  • Упоминания мест в текстах.
  • Отметки друзей.
Три подтверждения
Не публикуй геолокацию, пока не получил три независимых подтверждения: ориентир, карта, контекст.

Определение по метаданным

EXIF фото может содержать GPS-координаты. См. раздел «Метаданные».

10 · Метаданные

Артефакты

Скрытые данные в файлах: GPS, устройство, дата, автор, ПО.

Что такое метаданные

Метаданные — это служебная информация файла. Для фото — EXIF, для документов — свойства Office, для PDF — автор и ПО.

Что можно вытащить

  • GPS-координаты — точное место съёмки.
  • Дата и время — когда сделано.
  • Устройство — модель камеры/телефона.
  • ПО — чем редактировали.
  • Автор — имя в свойствах Office/PDF.
  • История правок — для документов.

Инструменты

Соцсети чистят EXIF
Большинство соцсетей удаляют EXIF при загрузке. Но: оригиналы в мессенджерах (Telegram «файлом»), email-вложениях, файлообменниках — сохраняют.

Своя гигиена

Перед публикацией своих файлов — чисти метаданные: exiftool -all= file.jpg. Это защита от обратной геолокации.

11 · Изображения и видео

Артефакты

Обратный поиск, распознавание, анализ визуальных данных.

Обратный поиск изображений

  • Google Images — базовый.
  • Yandex Images — силён по лицам и РФ.
  • Bing Visual Search — альтернатива.
  • TinEye — точные совпадения, история.
  • PimEyes — поиск по лицу (платно).
  • FaceCheck.ID — поиск по лицу.

Методика

  1. Обрежь фото до ключевого объекта.
  2. Ищи по нескольким фрагментам.
  3. Пробуй на нескольких поисковиках.
  4. Проверь на дубликаты (TinEye).
  5. Проверь на «стоковые» (может быть не оригинал).

Анализ визуала

  • Отражения в стекле/зеркале.
  • Тени и их направление.
  • Номера машин, вывески.
  • Одежда с логотипами.
  • Домашний интерьер (уникальные предметы).
  • Растительность (регион).
  • Погода (сверка с архивами).

Видео

  • Покадровое извлечение: ffmpeg -i video.mp4 frame_%04d.png.
  • Извлечение звука: ffmpeg -i video.mp4 -vn audio.wav.
  • Анализ фона, движения, языка.
  • Поиск по кадрам через Google/Yandex.

Deepfake и подделки

Проверяй: артефакты по краям лица, неестественные волосы, асимметрия, шум. Инструменты: InVID, Forensically, FotoForensics.

InVID
Плагин для проверки видео: разбивка на кадры, обратный поиск, метаданные, анализ манипуляций.

12 · Утечки данных

Артефакты

Что делать с утёкшими базами: как искать, как проверять, как использовать.

Типы утечек

  • Credential dumps — email + пароль.
  • PII dumps — ФИО, адрес, телефон, паспорт.
  • Corporate leaks — внутренние документы.
  • Forum dumps — посты, личные сообщения.
  • Combolists — комбинации email:пароль.

Где искать

  • HaveIBeenPwned — легально, по email.
  • DeHashed — платный агрегатор.
  • LeakCheck — платный.
  • IntelligenceX — коммерческая разведка.
  • Публичные трекеры — там, где индексируются базы.

HaveIBeenPwned — пример

# Через API
curl -s "https://haveibeenpwned.com/api/v3/breachedaccount/user@example.com" \
  -H "hibp-api-key: YOUR_KEY"

Что делать с базой

  1. Нормализуй: приведи к единому формату.
  2. Дедуплицируй.
  3. Извлеки релевантные записи (по цели).
  4. Обогати: добавь актуальные данные.
  5. Проверь актуальность пароля (не используй — верифицируй старые данные).

Риски и этика

Осторожно
Хранение и использование утечек в ряде юрисдикций — нарушение. Использование чужих паролей — преступление. Для защиты — ок. Для атаки — статья.

Защита от утечек

  • Уникальные пароли для каждого сервиса.
  • Менеджер паролей.
  • 2FA везде, где можно.
  • Почта-однодневка для регистраций.
  • Мониторинг утечек (HIBP Notify).

13 · People-search

Что это

People-search сервисы агрегируют публичные данные о людях: адрес, телефон, родственники, судимости. В основном США/ЕС, но есть и локальные.

Западные сервисы

  • Spokeo

  • BeenVerified
  • Intelius
  • TruthFinder

Регион СНГ

  • ВКонтакте (поиск по ФИО, городу, вузу).
  • Одноклассники.
  • Судебные базы (sudrf.ru, kad.arbitr.ru).
  • ЕГРЮЛ/ЕГРИП (налог).

  • Госуслуги (только для своих).

Методика поиска по ФИО

  1. Поиск в соцсетях по ФИО + город.
  2. Проверка судебных баз.
  3. Проверка реестров юрлиц.
  4. Проверка приставов.
  5. Проверка через people-search.
  6. Сверка с известными данными.
Однофамильцы
Всегда проверяй на однофамильцев. Ищи подтверждения: возраст, город, работа. Никогда не публикуй без 2–3 подтверждений.

Родственники и связи

  • Друзья в соцсетях.
  • Совместные фото.
  • Общие фамилии.
  • Адресные базы.
  • Судебные дела.

16 · Пайплайн доксинга

Доксинг

Сборка всего предыдущего в единый процесс.

Общая схема

Точка входа → Расширение → Связывание → Верификация → Досье

Этап 1. Точка входа

Один якорь: ник, email, телефон, фото, ФИО. С него начинается всё.

Этап 2. Расширение

  • Прогон по всем платформам (Sherlock).
  • Поиск в утечках (HIBP).
  • Поиск в поисковиках (dorks).
  • Соцсети (SOCMINT).
  • Инфраструктура (если есть домен/IP).

Этап 3. Связывание

Собранные сущности связываются между собой:

  • Один аватар на разных платформах.
  • Один email в bio.
  • Один телефон в утечке и в профиле.
  • Общие подписчики.
  • Совпадения по времени активности.

Этап 4. Верификация

  • Минимум 2–3 независимых подтверждения.
  • Проверка на однофамильцев.
  • Проверка на фейки.
  • Кросс-датировка событий.

Этап 5. Досье

Финальный документ: см. следующий раздел.

Стоп-линия
Публикация персональных данных с целью преследования, шантажа или причинения вреда — уголовно наказуемо. Пайплайн для защиты, аудита, журналистики, правоохраны — да. Для травли — нет.

Автоматизация

  • Recon-ng — модульный фреймворк.
  • SpiderFoot — автоскан по якорю.
  • Maltego — граф связей в реальном времени.
  • Свои скрипты на Python для нормализации.

17 · Составление досье

Доксинг

Как собрать финальный документ: структура, разделы, таймлайн, граф.

Структура досье

1. Идентификация
   - ФИО, дата рождения, город
   - Ники, аккаунты
   - Контакты (email, телефон)

2. Связи
   - Семья, друзья, коллеги
   - Компании, организации

3. Активы
   - Недвижимость, транспорт
   - Бизнес, доли, счета

4. Активность
   - Соцсети, посты, комментарии
   - Геолокации

5. Хронология
   - Таймлайн событий

6. Источники
   - Ссылки, скриншоты, архивы

7. Выводы
   - С уровнем уверенности

Таймлайн

Все события — в хронологию. Каждое событие: дата, источник, что подтверждает. Таймлайн выявляет паттерны: поездки, работу, отношения.

Граф связей

Узлы — люди, компании, аккаунты, телефоны. Рёбра — связи. Maltego или Gephi для визуализации. Граф показывает структуру окружения цели.

18 · Контр-OSINT

Доксинг

Как защитить себя от того, что описано выше.

Что о тебе знают

Проверь себя тем же набором: Sherlock по своим никам, HIBP по своим email, поисковики по своему имени. То, что найдёшь — увидят и другие.

Снижение следа

  • Ники — уникальные для каждого сервиса.
  • Email — алиасы (SimpleLogin).
  • Фото — без EXIF, без геометок.
  • Соцсети — приватность, чистка старых постов.
  • Пароли — менеджер + 2FA.
  • Домен — приватность WHOIS.
  • Телефон — не привязывать к публичным аккаунтам.

Цифровая гигиена

  1. Аудит аккаунтов раз в полгода.
  2. Удаление старых аккаунтов.
  3. Проверка утечек (HIBP).
  4. Разделение личного и публичного.
  5. Отдельные браузеры для разных задач.
  6. Проверка разрешений приложений.

Удаление данных

  • Google — «Удалить устаревший контент».
  • Yandex — «Удалить из поиска».
  • People-search — opt-out формы.
  • Соцсети — удаление старых постов.
  • Сайты — GDPR-запросы.

Защита от доксинга

  • Не публикуй в реальном времени (пост-фактум).
  • Не свети геолокацию.
  • Не используй один ник везде.
  • Не привязывай телефон к публичным аккаунтам.
  • Разделяй рабочие и личные аккаунты.
  • Проверяй, что видно в сторис (фон, отражения).
Главное
Ты не скроешься полностью. Задача — повысить стоимость сбора для того, кто тебя ищет. Каждый дополнительный шаг — фильтр.
